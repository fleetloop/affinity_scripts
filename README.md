<h1>Text Box Exporter 1.0.0</h1>

A useful script for moving text back and forth when making Picture Book dummies.

1. To get started, download the Affinity Layout persona template, Picture-Book-Dummy-32-page-Template.zip
2. Cut and paste the text from your manuscript into the pages
3. Edit your story, check for page turns, pacing, all the good editing stuff.
4. When you're satisfied, run the Text Box Exporter script.
5. An alert will pop up with all the text.
6. Select All, Copy, the hit Return to dismiss the alert.
7. Paste the text into your writing software (I use IA Writer and Scriviner).
8. Continue to tinker, obsess and self-doubt.
9. Cut and paste the text back into your Affinity doc, and repeat!
